Drop product photos here (e.g. tomatoes.jpg, pineapple.jpg).

To use a photo instead of the default icon for a product:
- In the Business Dashboard → Products → "Add a new product" form, paste a path
  like `assets/images/tomatoes.jpg` into the "Photo URL" field, or
- Edit the product's `image` field directly in js/store.js (defaultProducts list)
  if you want a photo to ship as part of the default catalogue.

Recommended: square or 4:3 images, at least 400px wide, JPG or WebP for smaller file size.
